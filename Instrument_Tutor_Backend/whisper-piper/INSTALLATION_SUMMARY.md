# 🛠️ Installation Summary - Voice Assistant Project

## 📦 System Tools & Build Dependencies

### 1. **CMake** (v4.1.2)
- **Purpose**: Cross-platform build system generator
- **Installation**: `winget install Kitware.CMake`
- **Usage**: Used to configure and generate build files for whisper.cpp
- **Location**: `C:\Program Files\CMake\`

### 2. **MinGW-w64 via MSYS2**
- **Purpose**: GNU Compiler Collection (GCC) for Windows
- **Installation**: `winget install msys2.msys2`
- **Package**: `mingw-w64-x86_64-toolchain`
- **Components Installed**:
  - GCC 15.2.0 (C/C++ compiler)
  - G++ (C++ compiler)
  - GDB (debugger)
  - make (build automation)
  - binutils (binary utilities)
- **Location**: `C:\msys64\mingw64\`

### 3. **Make (GnuWin32)**
- **Purpose**: Build automation tool
- **Installation**: `winget install GnuWin32.Make`
- **Alias Created**: `make` → `mingw32-make` (in ~/.bashrc)

### 4. **WinLibs (MinGW-w64)**
- **Purpose**: Additional MinGW distribution with modern GCC
- **Installation**: `winget install BrechtSanders.WinLibs.POSIX.UCRT`
- **Version**: GCC 15.2.0
- **Components**: Full toolchain including cmake, ninja, etc.

### 5. **Ninja Build System**
- **Purpose**: Fast build system (alternative to make)
- **Installation**: `winget install Ninja-build.Ninja`
- **Version**: 1.13.1

## 🎤 AI & Voice Processing

### 9. **whisper.cpp**
- **Purpose**: Fast C++ implementation of OpenAI's Whisper (speech-to-text)
- **Source**: Cloned from GitHub (ggerganov/whisper.cpp)
- **Build Configuration**: 
  - Built with Vulkan GPU support (`-DGGML_VULKAN=1`)
  - Using MinGW-w64 compiler
- **Location**: `./whisper.cpp/`
- **Executables**: `./whisper.cpp/build/bin/`
  - `whisper-cli.exe` (main transcription tool)
  - `whisper-bench.exe` (benchmarking)
  - `whisper-server.exe` (API server)
- **Model Downloaded**: whisper-large-v3-q8_0.gguf (1.54 GB)
- **Performance**: ~3.3x faster with GPU vs CPU

### 10. **Piper TTS**
- **Purpose**: Fast text-to-speech engine
- **Version**: 2023.11.14-2
- **Installation**: Downloaded from GitHub releases
- **Size**: 21.4 MB
- **Location**: `./piper/piper/`
- **Components**:
  - `piper.exe` (main TTS engine)
  - `espeak-ng.dll` (phoneme library)
  - `onnxruntime.dll` (neural network runtime)
- **Voice Model**: en_US-amy-low.onnx (60.18 MB)

## 🔄 How to Reinstall (if needed)

```bash
# Core build tools
winget install Kitware.CMake
winget install msys2.msys2

# In MSYS2 terminal:
pacman -Sy mingw-w64-x86_64-toolchain

# GPU support
winget install KhronosGroup.VulkanSDK

# Rebuild whisper.cpp
cd whisper.cpp/build
rm -rf *
cmake -G "MinGW Makefiles" -DGGML_VULKAN=1 ..
mingw32-make -j$(nproc)

# Reinstall Python packages
pip install sounddevice numpy scipy requests
```
